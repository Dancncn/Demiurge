# GOAI 赛道一初赛提交材料

本目录按参赛手册第 5.2 节和附录 A、B、C 整理。手册要求初赛必交“作品简介”和“方案 PPT / PDF”，可选提交可执行 AgentTeams 代码包；同时要求提交 Agent Identity 清单、核心 Skill 清单，并给出项目一页纸建议结构。

## 提交顺序

1. `01-作品简介.md`：500 字以内，可直接粘贴到报名系统。
2. `04-Agent-Identity清单.md`：按附录 A 字段填写，作为仓库中的设计说明。
3. `05-Skill清单.md`：按附录 B 字段填写，作为仓库中的复用说明。
4. `07-提交检查表.md`：上传前逐项复核。

方案 PPT、项目一页纸和 ZIP 代码包是本地交付材料，不纳入 Git；比赛系统只提交本仓库链接时，评委从根目录 README 和本指南进入可运行 Demo。

本地总包为 `../GOAI-赛道一-Demiurge-初赛提交包.zip`，仅用于需要上传附件的场景；压缩包内只保留一个版本的方案 PPT，避免评委误开旧稿。

## 提交前仍需人工填写

- 团队名称、成员姓名与联系方式；
- 报名系统中的仓库链接；
- 如主办方临时发布新的文件命名或大小限制，以官方平台最新通知为准。

## 公开边界

本场景因企业信息安全要求，仅使用公开资料、虚构试验文档和合成测量数据重建业务方法。材料不包含真实企业、车型、ECU、A2L、CAN 日志、试验阈值、内网地址或密钥，也不代表真实生产验收结论。
