# GOAI 赛道一初赛提交检查表

依据参赛手册第 5.2 节、第 8–13 章和附录 A–C。

## 报名系统必交

- [ ] 作品简介已粘贴，正文不超过 500 字；项目名称约 20 字。
- [ ] 最新方案 PPT 为 `GOAI-赛道一-方案PPT.pptx`，没有上传旧版 `goai-demo*.pptx`。
- [ ] PPT 已覆盖场景与价值、方案设计、Skill/工具集成、可行性与落地计划。
- [ ] 团队名称、成员、联系方式和仓库链接已替换“待填写”。

## 模板型材料

- [ ] Agent Identity 清单包含 Name、Role、Capabilities、Inputs、Outputs、Dependencies、Decision Boundary、Trace。
- [ ] Skill 清单包含名称、类型、场景、输入、输出、条件、依赖、失败处理、权限安全、复用价值。
- [ ] 项目一页纸包含项目与团队、场景问题、方案、多 Agent、Skill/工具、Demo 结果、开源、业务价值、计划与对接需求。

## 可选 AgentTeams 代码包

- [ ] 入口：`python competition/agentteams/demo/run.py`。
- [ ] 依赖：Python 3.10+，离线默认无第三方 Python 依赖。
- [ ] 配置：样例配置与 MCP 示例不含真实密钥。
- [ ] 样例输入：A2L、CAN/MDA 回放、试验大纲、流程手册、报告规范。
- [ ] 样例输出：XLSX、JSON、DOCX、Markdown 报告。
- [ ] 运行证据：UI 截图、`ui-invocation.json`、`run-evidence.json`、checksum、逐规则结果。
- [ ] AgentTeams 声明、MCP 契约和 8 个 Skill 已包含。

## 合规与红线

- [ ] 不包含 API Key、内网地址、真实 A2L/CAN/MDF、车型、真实阈值或企业报告模板。
- [ ] 明确披露已有 Demiurge 项目基础、GOAI 分支新增贡献和 MIT 许可兼容性。
- [ ] 商业 API/闭源模型仅为可选复核，已说明调用范围、替代方案和可复现影响。
- [ ] 真实桌面、台架、生产数据或正式签署动作保留人工确认、回滚和审计边界。
- [ ] 不宣称合成 Demo 是真实企业验收或生产结论。
